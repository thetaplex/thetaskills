# README checklist

Read the README and check each item. Write the missing parts yourself, in the README's existing voice. Don't pad it.

- [ ] **What it does:** one or two sentences at the top.
- [ ] **Why it exists:** the problem it solves, or who it's for.
- [ ] **Install,** with named prerequisites and links to install them.
- [ ] **Quickstart:** the shortest path to a first result. Every command runs as written.
- [ ] **Usage:** the main ways to use it, or a link to the docs.
- [ ] **Links:** docs, changelog, contributing.
- [ ] **License:** names the license and links to `LICENSE`.
- [ ] **At most three badges.**
- [ ] **No private details:** internal hostnames, personal paths, private URLs or credentials.

Detail belongs in `docs/`, not the README. Make sure the GitHub repo description (the `description` line from `check.sh`) matches the README's opening line.
