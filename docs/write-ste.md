# write-ste

Written for small local models (4B to 8B parameters) and works in any agent. See [Writing skills for small models](writing-skills.md) for how these skills are built.

Say something like **"fix the style errors in this draft"**.

The ASD-STE100 Simplified Technical English rules, a script that checks the measurable ones, the word swaps it asks for most, and how to fix its report one line at a time.

## What it writes

the draft it fixes. It installs nothing.

## Requirements

Python 3 (standard library only), and an agent that can read, create and edit files and run shell commands.

## Uninstall

Remove the skill as described in [INSTALL.md](../INSTALL.md#uninstall).
