# Security policy

## Supported versions

thetaskills is in alpha (0.x). Until 1.0, security fixes go only to `main`.

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub: on the repository page open **Security > Report a vulnerability** ([direct link](https://github.com/thetaplex/thetaskills/security/advisories/new)).

Include the affected skill and commit, steps to reproduce, and the impact you expect. We aim to acknowledge reports within 3 working days and to agree a disclosure date with you once a fix is ready.

Issues of particular interest: skill scripts that run unexpected commands, install unverified software, or leak secrets.
